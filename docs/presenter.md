# 発表者ビューと操作

## 操作キー

| キー | 動作 |
|---|---|
| `→` / `Space` / `PageDown` / 画面右側クリック | 次へ |
| `←` / `PageUp` / 画面左側クリック | 前へ |
| `Home` / `End` | 最初 / 最後 |
| `f` | フルスクリーン |
| `o` / `Esc` | スライド一覧（オーバービュー） |
| `p` | 発表者ビュー（別ウィンドウ） |
| `r` | リモコン用 QR の表示（`ippon serve` のときのみ） |

- スマホでは左右スワイプでもページ送りできます。
- URL の `#12` で 12 枚目から開けます。

## タイマー

表紙（1 枚目）から次に進むと、右下でタイマーが動き始めます。表紙に戻るとリセットされます。

## 発表者ビュー（`p`）

`p` を押すと別ウィンドウで発表者ビューが開きます。手元には次が表示されます。

- 現在のスライドと次のスライド
- `::note::` で書いた**発表者ノート**
- 経過タイマーと時計

本番側（プロジェクタに映す画面）は通常表示のままです。どちらのウィンドウで `→` / `←` を
押しても両画面が同期します。`p` / `Esc` で閉じます。

発表者ノートの書き方は [Markdown 記法 › 発表者ノート](syntax.md#発表者ノートnote) を参照してください。

## スマホをリモコンに

発表者ノートやページ送りを手元のスマホで行いたい場合は [`ippon serve`](serve.md) を使います。
