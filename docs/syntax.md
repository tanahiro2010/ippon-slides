# Markdown 記法

ippon は手書きの Markdown サブセットパーサーです。普通の Markdown に、スライド向けの
記法を少し足したものと考えてください。

## frontmatter

ファイル先頭に `key: value` だけの簡単な frontmatter を書けます。

```md
---
title: 発表タイトル
author: あなたの名前
description: 説明（任意）
lang: ja
---
```

- `title` … HTML の `<title>`。
- `author` / `description` … `<meta>` に入る。
- `lang` … `<html lang>`（既定 `ja`）。

## スライドの区切り

`---` だけの行でスライドを分けます。コードフェンス内の `---` は区切りになりません。

```md
# 1 枚目

---

# 2 枚目
```

## ディレクティブ

スライドの **1 行目**に `::...::` を置くと、そのスライドの見せ方を指定できます。
`::center bg=blue size=2::` のようにまとめて書けます。

| ディレクティブ | 意味 |
|---|---|
| `::center::` | 中央寄せの大きな文字（1 枚 1 メッセージ向け） |
| `::title::` | 表紙。最後の段落はページ下に寄る |
| `::wide::` | 左右の余白を詰める（スクリーンショット向け） |
| `::bg=blue::` | 背景色。`blue` / `orange` / `purple` / `red` / `green` / `black` / `white`、または `#rrggbb` |
| `::size=1.5::` | 文字サイズの倍率 |

`bg=white` のときは自動で明るいテーマ（濃い文字色）になります。

## 2 カラム（`::right::`）

`::right::` の行から右カラムが始まります。先頭の見出しはカラムの外（上）に出ます。

```md
## 見出し

- 左に説明
- もうひとつ

::right::

\`\`\`ts
const app = new Hono()
\`\`\`
```

カラム幅は `::right left-wide::`（1.4 : 1）、`::right right-wide::`（1 : 1.4）で変えられます。

## 本文の記法

- 見出し: `#` / `##` / `###`
- 箇条書き: `-` `*`、番号付き `1.`。インデントでネスト。
- **太字** `**太字**` はアクセントカラーになる。
- `` `インラインコード` ``、*斜体*、リンク `[text](url)`、画像 `![alt](src "caption")`。
- 引用 `> `、表（`|` 区切り。見出し行の下に `---`、`:--` などで寄せを指定。セル内の `|` は `\|`）。
- 矢印 `→` は少し薄く表示される。
- `-# 注釈` … 小さい注釈。

## コードブロック

````md
```ts
const x = 1
!! const y = 2   // 行頭に "!! " を付けるとその行が強調される
```
````

ハイライト対応: `hcl` / `tf` / `terraform`、`sh` / `bash` / `shell` / `zsh`、`json`、
`js` / `ts` / `jsx` / `tsx`、`console`。

`console` は `$ ` で始まる行をコマンド、`Error` を含む行をエラーとして色分けします。

ビルド後の HTML ではコードブロックの右上に **Copy ボタン**が出ます。

## 発表者ノート（`::note::`）

`::note::` 以降はそのスライドの発表者ノートになります。本番スライドには表示されず、
[発表者ビュー](presenter.md)やスマホリモコンだけに出ます。

```md
本番に出る内容

::note::

ここは手元のメモ。
```

## HTTP プレイグラウンド（`::http::`）

`::http method=GET url=https://...::` でスライド上に HTTP レスポンスを表示できます。
詳しくは [HTTP プレイグラウンド](http.md) を参照してください。
