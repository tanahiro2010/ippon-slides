# スマホをリモコンにする（`ippon serve`）

```sh
ippon serve slide.md
```

ローカルにサーバを立て、端末に **QR コード**を表示します。スマホのカメラで読み取ると
リモコン画面が開き、手元でスライドを操作できます。

## できること

- **ページ送り**（◀ ▶ / 最初 / 最後）
- **タイマーのリセット**と経過時間の確認
- **発表者ノートの確認**（`::note::` で書いた内容）

本番画面・発表者ビュー・スマホはリアルタイムに同期します。

## 使い方

1. PC とスマホを**同じ Wi-Fi** に繋ぐ。
2. `ippon serve slide.md` を実行する。
3. 端末に出た QR をスマホのカメラで読み取る（または表示された URL を開く）。
4. PC では表示された `この PC で開く:` の URL をブラウザで開いて発表する。

QR は次の場所にも出ます。

- **発表者ビュー**（`p` キー）の右下。
- 本番画面で **`r` キー**を押すと QR を全画面表示（もう一度 `r` / `Esc` で閉じる）。

## 仕組み

- 通信は **SSE（サーバ→クライアント）+ `POST /cmd`（クライアント→サーバ）** の小さな pub/sub だけ。
  WebSocket も外部サービスも使いません（ランタイム依存ゼロのまま）。
- 本番画面が「真実のソース」。スマホは状態を受け取って表示し、操作をサーバ経由で送ります。
- タイマーは端末間の時計ずれを避けるため、絶対時刻ではなく経過時間（elapsed）をやり取りします。
- 途中から繋いだスマホにも、直近の状態（現在のスライド・経過時間）がすぐ届きます。

## セキュリティ

- リモコンの URL には**ランダムなトークン**が付き、正しいトークンでないと
  デッキ・リモコン・配信（`/` `/remote` `/events` `/cmd`）にアクセスできません。
- サーバは LAN に公開されます（画像などの静的ファイルはトークン無しで配信）。公開したくない
  ネットワークでは実行しないでください。

## オプション

| オプション | 意味 |
|---|---|
| `-p, --port <n>` | 待ち受けポート（省略時は空きポートを自動選択） |
| `--css <file>` | 追加の CSS |

終了は `Ctrl+C` です。

## うまく繋がらないとき

- **同じ Wi-Fi に繋がっているか**確認してください（スマホがモバイル回線だと繋がりません）。
- Wi-Fi の「**クライアント分離（AP isolation）**」が有効だと、スマホから PC に到達できません。
  ゲスト Wi-Fi などで起こりがちです。テザリングや別の Wi-Fi を試してください。
- ファイアウォールがポートをブロックしていないか確認してください。
