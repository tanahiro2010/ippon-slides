# ippon-slides ドキュメント

Markdown から「1 枚 1 メッセージ」のスライドを作る CLI、`ippon` の詳しいドキュメントです。
概要とインストールは[リポジトリの README](../README.md) を参照してください。

## 目次

- [はじめに](getting-started.md) — インストール・クイックスタート・基本の流れ
- [Markdown 記法](syntax.md) — スライド区切り・ディレクティブ・2 カラム・コード・表
- [HTTP プレイグラウンド（`::http::`）](http.md) — スライド上に HTTP レスポンスを表示する
- [スマホをリモコンにする（`ippon serve`）](serve.md) — QR で繋いでページ送り・ノート確認
- [発表者ビューと操作](presenter.md) — 発表中のキー操作・タイマー・発表者ノート
- [見た目を変える](theming.md) — `--css` と CSS 変数
- [CLI リファレンス](cli.md) — コマンドとオプションの一覧

## 特徴

- **単一 HTML ファイル**を出力（CSS / JS はすべてインライン）。配布も共有も 1 ファイル。
- **ランタイム依存ゼロ**。PDF 出力はローカルの Chrome を直接使う。
- 16:9 の **PDF** 出力。
- HTTP プレイグラウンド、スマホリモコン、発表者ビューを内蔵。
