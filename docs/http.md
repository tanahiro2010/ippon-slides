# HTTP プレイグラウンド（`::http::`）

スライドに HTTP リクエストの結果（ステータス・レスポンスタイム・ヘッダー・JSON ボディ）を
表示する機能です。API 紹介やデモに向いています。

```md
::http method=GET url=https://api.github.com/repos/tanahiro2010/ippon-slides::
```

- `method` を省略すると `GET` です。
- URL を裸で書く `::http https://...::` も使えます。
- 単独の行に書いてください（コードフェンス内は対象外）。

## 仕組み：ビルド時に焼き込み

レスポンスは **ビルド時に Node 側で取得して HTML に焼き込みます**。ブラウザの `fetch` と違い
CORS の制約を受けないため、どんな API でも表示でき、オフラインでも PDF でもそのまま映ります。

- 本番でネットワーク・レート制限・CORS に邪魔されない（= デモが安全）。
- 同じ `method + URL` は 1 回だけ取得します。
- 取得はタイムアウト 10 秒、ボディは 20KB まで（超過分は省略表示）。

## 再送信ボタン

焼き込んだ結果の横に「再送信」ボタンが出ます。押すと**ブラウザからライブで**叩き直します。

- この経路は通常の `fetch` なので **CORS の対象**です。相手が CORS を許可していれば最新の結果に
  差し替わります。
- 失敗した場合は理由を表示し、**ビルド時のスナップショットに戻します**。

## 取得を止める

ビルド時の取得をしたくないときは `--no-fetch` を付けます。この場合は「未取得」のプレースホルダが
焼き込まれ、再送信ボタンから取得する形になります。

```sh
ippon build slide.md --html --no-fetch
```

## 表示される内容

- **ステータス**：2xx / 3xx / 4xx / 5xx で色分け。
- **レスポンスタイム**：ビルド時は Node、再送信時はブラウザで計測。
- **ヘッダー**：折りたたみ（`<details>`）で件数付き表示。
- **ボディ**：JSON は整形してシンタックスハイライト。それ以外は素のテキスト。
