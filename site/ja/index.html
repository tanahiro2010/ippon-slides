ippon は Markdown を「1 枚 1 メッセージ」のスライドに変換します。CSS/JS 全部入りの単一 HTML、そして 16:9 の PDF。ゼロ依存。ずっとあなたのもの。

はじめる GitHub でスター npx ippon-slides init

道具は消え、メッセージだけが残る。

名前の ippon（一本） は柔道で勝負を決める一本から。1 枚で 1 つのメッセージを決める。巧さは装飾ではなく引き算にあります。箇条書きが溢れたら、それはフォントを縮めるのではなくスライドを分ける合図です。

迷ったら、足すのではなく削る。スライドからも、この道具からも。

クラウドなし。専用ビューアなし。ランタイム依存なし。デッキはただの HTML ファイルで、どの端末でも、何年後でも開けます。

全部、1 ファイルに

厳選した機能だけ。ひとつひとつが居場所を持っています。

📄

単一の自己完結 HTML

CSS も JS もインライン。メールでも Git でもオフラインでも開ける 1 ファイル。ビルドサーバも CDN も不要。

🧩

ランタイム依存ゼロ

ビルドに使うのは TypeScript だけ。PDF 出力はブラウザを同梱せずローカルの Chrome を直接駆動。

🖨️

16:9 PDF 出力

--pdf でフォントも色もそのままの 16:9 PDF を生成。

📱

スマホがリモコン

ippon serve が QR を表示。読み取ればページ送り・タイマー・発表者ノートを手元で。LAN 上で動き WebSocket 不要。

🌐

HTTP プレイグラウンド

::http:: で実レスポンス（ステータス・時間・ヘッダー・整形 JSON）をビルド時に焼き込み（CORS 無関係）＋ライブ再送信。

🔍

拡大とスポットライト

画像やコードをクリックで拡大。行をクリックすると周囲が暗くなり 1 行だけ強調。コード解説に最適。

🧑‍🏫

発表者ビュー

p で現在・次のスライド、発表者ノート、タイマーを別ウィンドウに。両画面は同期。

🎨

テーマ変更

--css で少数の CSS 変数を上書き。既定のままですぐ発表に臨めます。

はじめに

インストール不要。npx でその場で実行（Node.js 18.17+）。

1 · 作って、ビルド

# サンプルを作る
npx ippon-slides init

# 単一 HTML を作る
npx ippon-slides build slide.md --html

# 16:9 PDF も
npx ippon-slides build slide.md --pdf

Markdown 記法

ふつうの Markdown に、スライド用の記法を少しだけ。詳細は ドキュメント。

記法意味
---スライドの区切り（コードフェンス内は無視）。
::center::中央寄せの大きな 1 メッセージ。
::title::表紙。最後の行が下に沈む。
::bg=blue:: / ::size=1.5::背景色・文字サイズ倍率。
::right::2 カラム（left-wide / right-wide で 1.4:1）。
::note::以降は発表者ノート（発表者ビュー・スマホのみ）。
::http method=GET url=…::HTTP リクエストのプレイグラウンド。
!! （行頭）コードのその行を強調。
 
# LAN で配信し QR を表示
npx ippon-slides serve slide.md

スマホをリモコンに

ippon serve が QR を表示。読み取るとスマホがリモコンになり、ページ送り・タイマー・発表者ノートを手元で操作できます。通信は LAN 上の SSE だけ（WebSocket も外部サービスもなし）。ペアリング URL はランダムトークンで保護されます。

FAQ

Markdown からスライドを作るには？

npx ippon-slides init でサンプル slide.md を作り、npx ippon-slides build slide.md --html で単一の slide.html を出力します。--- で区切り、1 枚に 1 メッセージ。

出力はオフラインで動く？

はい。CSS/JS 全部入りの 1 ファイルなので、ネットワークもサーバーも依存もなしで、どのブラウザでも開けます。

PDF に書き出せる？

はい、--pdf で。ローカルの Chrome / Chromium / Edge を使って 16:9 PDF を印刷するので、重いものを同梱しません。

スマホから操作できる？

はい。ippon serve が QR を表示。読み取ればページ送り・タイマー・発表者ノートを LAN 上の SSE で同期して操作できます。

無料でオープンソース？

はい。MIT ライセンスで npm に公開、ランタイム依存はゼロです。
