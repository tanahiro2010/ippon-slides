One message per slide.

ippon turns Markdown into a one-message-per-slide deck — a single self-contained HTML file, and a 16:9 PDF. Zero dependencies. Yours forever.

Get started Star on GitHub npx ippon-slides init

The tool disappears. The message stays.

Named after ippon — the single decisive point in judo. One slide, one message. The craft is in subtraction, not decoration: if a bullet list is overflowing, that is a sign to split the slide, not to shrink the font.

When in doubt, remove — from the slide, and from the tool.

No cloud. No proprietary viewer. No runtime dependencies. Your deck is a plain HTML file that opens in any browser, on any machine, for years.

Everything, in one file

A focused feature set — each one earns its place.

Single self-contained HTML

CSS and JS are inlined. One file you can email, commit, or open offline — no build server, no CDN.

Zero runtime dependencies

Only TypeScript is used to build it. PDF export drives a local Chrome directly instead of bundling a browser.

16:9 PDF export

--pdf renders a crisp 16:9 PDF from your deck, fonts and colors intact.

Phone remote

ippon serve shows a QR code. Scan it to advance slides, reset the timer and read speaker notes — over your LAN, no WebSocket.

Live HTTP playground

::http:: embeds a real request and response — status, time, headers, pretty JSON — baked at build time (CORS-free) with a live re-send button.

Spotlight and zoom

Click an image or a code block to zoom. Click a line to spotlight it while the rest dims — made for walking through code.

Presenter view

Press p for current and next slide, speaker notes and a timer in a second window, kept in sync.

Themeable

Override a few CSS variables with --css. Start with sensible defaults and present immediately.

Quick start

No install required — npx runs it on demand. Needs Node.js 18.17+.

01Create and build

# create a sample deck
npx ippon-slides init

# build a single HTML file
npx ippon-slides build slide.md --html

# ...and a 16:9 PDF
npx ippon-slides build slide.md --pdf

Markdown syntax

Plain Markdown, plus a few slide-specific directives. Full reference in the docs.

SyntaxWhat it does
---Split into a new slide (ignored inside code fences).
::center::Big, centered one-message slide.
::title::Title slide; the last line sinks to the bottom.
::bg=blue:: / ::size=1.5::Background color and text-size multiplier.
::right::Start a second column (left-wide / right-wide for 1.4:1).
::note::Everything after becomes a speaker note (presenter & phone only).
::http method=GET url=…::Embed a live HTTP request playground.
!! (line prefix)Highlight that line inside a code block.

A live HTTP playground in your deck

Great for API talks and demos. The response — status, response time, headers and pretty-printed JSON — is fetched in Node at build time, so it is immune to CORS and prints into the PDF. A “re-send” button re-runs it live in the browser.

Demos that never fail on stage, because the result is already there.

Turn your phone into the remote

ippon serve prints a QR code. Scan it and your phone becomes a remote: advance slides, reset the timer, and read your speaker notes in your hand. It syncs over Server-Sent Events on your local network — no WebSocket, no external service — and the pairing URL is protected by a random token.

CLI

Three commands, sensible defaults.

ippon build <in.md> --html --pdf -o dist/Build HTML and/or PDF.
ippon serve <in.md> [-p 7000]Serve locally + phone remote (QR).
ippon init [file]Write a sample deck.
ippon build … -wWatch and rebuild on save.

FAQ

How do I turn Markdown into slides?

Run npx ippon-slides init to create a sample slide.md, then npx ippon-slides build slide.md --html to produce a single self-contained slide.html. Separate slides with --- and keep one message per slide.

Does the output work offline?

Yes — one HTML file with all CSS and JS inlined. No network, no server, no runtime dependencies. It opens in any browser, even years later.

Can I export to PDF?

Yes, with --pdf. ippon drives a locally installed Chrome, Chromium or Edge to print a 16:9 PDF, so nothing heavy is bundled.

Can I control slides from my phone?

Yes. ippon serve shows a QR code; scanning it gives you a remote for navigation, the timer and your speaker notes, synced over SSE on your LAN.

Is it free and open source?

Yes — MIT licensed, published on npm, with zero runtime dependencies.

What makes it different from other Markdown slide tools?

One message per slide (the Takahashi method), a single self-contained HTML file, zero dependencies, plus a phone remote, a live HTTP playground, click-to-zoom with per-line spotlight and a presenter view — no cloud required.
